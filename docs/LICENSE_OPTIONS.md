# Code license candidates for author review

No LICENSE has been selected or granted by this local candidate. Confirm the actual code copyright holders, institutional/employer rights and any incorporated third-party code first. A missing or unfinished author identity is not replaced with an invented name.

| Candidate | Practical distinction | Official text and guidance |
|---|---|---|
| MIT | Short permissive option; retains copyright/license notice | [MIT](https://choosealicense.com/licenses/mit/) |
| BSD 3-Clause | Permissive option with a restriction on using contributor names for endorsement | [BSD 3-Clause](https://choosealicense.com/licenses/bsd-3-clause/) |
| Apache 2.0 | Permissive option with express patent terms and notice/change obligations | [Apache 2.0](https://choosealicense.com/licenses/apache-2.0/) |

MIT is a simple candidate if all holders agree to a permissive release and upstream terms allow it. Choose Apache 2.0 if its patent provisions fit the holders' needs; BSD 3-Clause is another common permissive option. This comparison does not choose on behalf of the authors.

Before public release, put the selected unmodified license text in a root `LICENSE` file and fill the correct holder and year where required. Do not apply the software license to RELAX, WESAD, private Polar records, manuscript rights or third-party dependencies. Data terms remain separate. If third-party source has been incorporated, retain its actual license and attribution instead of declaring everything newly owned.

Sources checked on 28 October 2026. The linked pages are maintained by GitHub's Choose a License project.
