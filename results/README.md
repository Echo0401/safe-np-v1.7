# Frozen aggregate reference tables

`reference/` contains saved group summaries selected for local release review. Tables named `participant_method_summary` summarize across participants and do not contain individual participant rows. Individual query predictions, time keys, subject metrics and training logs are excluded.

These tables support inspection and numeric comparison; they do not recreate the underlying inputs. Main and ablation multiplicity families differ. See the method evidence note and validation record for the exact scope. Approval to publish these aggregates remains an author decision.
