# Third-party and data rights review

Core runtime dependencies are NumPy, pandas, SciPy, scikit-learn and PyTorch. Dependencies are referenced through requirements rather than vendored. Their own licenses continue to apply. Optional Parquet/Excel and figure dependencies have separate requirements files.

The original project did not supply a complete source-authorship and third-party attribution manifest. This candidate therefore does not certify that all code can be relicensed under a single license. Authors should confirm the origin of copied snippets and retain any required notices before public release. RELAX and WESAD are external datasets; Polar is privately collected. A software license cannot grant rights to any of these data.
